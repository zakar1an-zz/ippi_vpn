Помощь и настройка

Инструкция

Выбери устройство, на котором хочешь пользоваться ippi VPN.

Для подключения понадобится персональная конфигурация ippi VPN. Она появится в личном кабинете после настройки серверов и выдачи доступа.

Инструкция · iOS

iPhone и iPad

Подключение через приложение INCY.

Приложение INCY iOS

Установи INCY из официального источника, доступного для твоего устройства.

Ссылка на скачивание будет добавлена

Как подключиться

  1. Открой App Store и найди приложение INCY. Установи его, если оно доступно в твоём регионе.
  2. Открой INCY и разреши добавление VPN-конфигурации, если iPhone покажет системный запрос.
  3. Вернись в личный кабинет ippi VPN и получи свою персональную конфигурацию — QR-код или ссылку подписки.
  4. В INCY выбери импорт конфигурации. Если используешь QR-код, отсканируй его; если ссылку — вставь её в соответствующее поле.
  5. Сохрани добавленный профиль, выбери его в приложении и нажми кнопку подключения.
  6. Подтверди системный запрос iOS на создание VPN-подключения. После успешного соединения приложение покажет активный статус.
Названия пунктов и расположение кнопок могут немного отличаться в зависимости от версии INCY. Не используй чужие конфигурации — подключай только свой профиль ippi VPN.

Инструкция · Android

Android

Подключение через приложение INCY.

Приложение INCY Android

Установи INCY из официального источника, который будет указан здесь.

Ссылка на скачивание будет добавлена

Как подключиться

  1. Скачай и установи INCY из официального источника. Не устанавливай APK-файлы с неизвестных сайтов.
  2. Открой INCY и ознакомься с первым запуском приложения.
  3. В личном кабинете ippi VPN получи персональную конфигурацию — QR-код или ссылку подписки.
  4. В INCY нажми добавление профиля. Выбери сканирование QR-кода либо импорт по ссылке и используй свои данные ippi VPN.
  5. Сохрани профиль, выбери его в списке и нажми кнопку подключения.
  6. Разреши Android создать VPN-подключение, если появится системный запрос. Дождись статуса подключения в INCY.
Интерфейс может отличаться в зависимости от версии Android и INCY. Для стабильной работы используй актуальную версию приложения.

Инструкция · Windows

Windows

Подключение через клиент v2rayN.

Приложение v2rayN Windows

Скачай актуальную версию v2rayN из официального репозитория проекта.

Официальная ссылка будет добавлена

Как подключиться

  1. Скачай подходящую сборку v2rayN для своей версии Windows из официального источника.
  2. Распакуй архив в отдельную папку и запусти приложение. Если Windows запросит разрешение, проверь источник файла перед подтверждением.
  3. В личном кабинете ippi VPN получи персональную VLESS-конфигурацию или ссылку подписки.
  4. В v2rayN импортируй конфигурацию: используй импорт из буфера обмена для скопированной ссылки либо импорт из файла, если тебе выдали файл конфигурации.
  5. Проверь, что добавленный сервер появился в списке. Выбери его и включи системный прокси или режим, который будет указан в инструкции ippi VPN.
  6. Проверь подключение. Если соединение не устанавливается, скопируй сообщение об ошибке и отправь его в поддержку ippi VPN.
Конкретные пункты меню v2rayN зависят от версии клиента. Персональные ссылки и конфигурации никому не пересылай: они дают доступ к твоей подписке.
